projector.

Install the Wi-Fi animation player on your CYD using a USB data cable and your browser.

Compatible hardware

3.2″ QD3223 / E32R32P and 3.5″ Freenove E32R35T. Both use the classic ESP32 and resistive touch.

USB INSTALLER

1. Pick your board

Match the screen size and driver to your board or order listing.

2. Connect & install

  1. Plug the CYD into your computer with a USB data cable.
  2. Click the button below and select its serial port.
  3. Confirm installation and keep the board connected until it finishes.

Installing replaces the program on the connected ESP32. Check the board and display before continuing.

Open this page directly in desktop Chrome or Edge to connect over USB.Open this page directly over HTTPS to connect over USB.

Select your board to enable USB installation.

3. After installation

No serial port appears

Try another USB data cable, close Arduino Serial Monitor, and reconnect. If you opened the installer in a preview, open its URL in a separate browser tab. If the port opens but the board cannot synchronize, hold BOOT while connecting and release it when writing begins.

Load your first animation

Download the spinning cube test animation and copy it to the root of a FAT32 microSD card. For your own loops, put a multi-frame .rgb or .rgbv file in the root of the microSD card. Use 320 × 240, RGB565 little-endian, 10 fps, with no file header. On the 3.5″ model, existing clips scale to fit. For native 480 × 320 files, add .480x320 before the extension, for example portal.480x320.rgb. Insert the card and restart. Tap the display to advance.

Transfer animations over Wi-Fi

Start the player with at least one valid animation on the card. Once playback begins, join HologramPlayer using password hologram. Open http://192.168.4.1 on that device to manage your files.
