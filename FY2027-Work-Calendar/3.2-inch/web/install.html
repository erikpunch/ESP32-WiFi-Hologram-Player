Install to original 3.2″ hologram board

Connect your CYD with a USB data cable in Chrome/Edge on desktop. This installer needs its compiled firmware beside its manifest in an HTTPS-hosted folder. The zip includes a GitHub Actions workflow to generate it.

This browser does not support Web Serial. Use desktop Chrome or Edge.

Important: Installing the calendar replaces the hologram-player firmware on that ESP32. Existing stored data may be lost on full erase. Don't flash your only working projector until you've tested a spare board.
